# Обновления SmartVoice.TJ🇹🇯

Опубликованная версия: [SmartVoice 5.2.31-TJ](https://github.com/UMEDJON12/smartvoice-tj-updates/releases/tag/v5.2.31-TJ).

Подготовлена **SmartVoice 5.2.32-TJ (code 4148), SmartVoice-TJ40.apk**.

**[Открыть черновик 5.2.32 для проверки и публикации](https://github.com/UMEDJON12/smartvoice-tj-updates/releases/tag/untagged-87423b01600f21babe0f)**

APK и update.json уже загружены и независимо проверены. Новый выпуск ещё не опубликован.

1. Скачайте APK40 и установите поверх своей SmartVoice без удаления данных. Новая логика начинает работать после установки.
2. Проверьте ввод специальных букв по одной: ғ, ӣ, қ, ӯ, ҳ, ҷ, затем обычную букву. Проверьте основной/аварийный голоса и сохранённые назначения.
3. Проверьте открытие по значку, ручную проверку и выключение автоматической проверки. Если установлен code4148, а опубликован4147, отсутствие предложения обновиться правильно.
4. После проверки откройте черновик под UMEDJON12, нажмите **Edit → Publish release**. **Set as latest release** оставьте включённым. Загружать файлы самому не нужно.

Исправлены пустая озвучка отдельных букв и ошибочная блокировка всего голоса. Таджикский исключён из языковых списков и автоматического распознавания. Прежнее автоназначение при импорте/скачивании сохранено.

Проверка обновлений добавлена к настоящему launcher, UmedjonQuickControlActivity. Уже найденное обновление показывается из проверенного кэша; новый выпуск проверяется по короткому JSON. Авто-проверка — при входе и раз в минуту только при видимом интерфейсе. Ручная кнопка даёт немедленное окно состояния. Первое обнаружение неизвестного выпуска зависит от сети, очереди Actions и CDN.

Новый канал: `https://raw.githubusercontent.com/UMEDJON12/smartvoice-tj-updates/main/updates/stable.json`. Workflow `.github/workflows/publish-update-channel.yml` обновляет его только после публикации и проверки публичных файлов/подписи. Черновики и пререлизы не предлагаются. Прежний `/releases/latest/download/update.json` сохраняется для старых клиентов. Для теста обновления из APK40 потребуется следующий больший code.

APK остаются в Download/SmartVoice после установки. Пакет `tts.smartvoice.umedjon`; Full имеет отдельную ветку и пакет.

Проверки: [Actions](https://github.com/UMEDJON12/smartvoice-tj-updates/actions/runs/40454545137) и `checks/upload-check-result.json`. Проверены скачанные APK/JSON, SHA256, размеры, версия, пакет и исходный сертификат. Пройдено 46 781 компьютерная проверка. На физическом телефоне сборка не тестировалась.

Для следующего агента: `tools/prepare_upload_request.py`, `tools/direct_upload_client.py`, `.github/workflows/direct-draft-upload.yml` и новый publisher. Одноразовые сессии загрузки; постоянные токены и Android signing key не публикуются. Новую версию оставлять draft до решения владельца.
