# Обновления SmartVoice.TJ🇹🇯

Подготовлен **SmartVoice 5.2.30-TJ (code4146), SmartVoice-TJ38.apk** — обычная версия `tts.smartvoice.umedjon`.

**[Открыть черновик 5.2.30 для проверки и публикации](https://github.com/UMEDJON12/smartvoice-tj-updates/releases/tag/untagged-3cdde59001ee34614190)**

APK и `update.json` уже загружены и независимо проверены. Выпуск ещё не опубликован.

1. Войдите под UMEDJON12. Скачайте APK38 и установите поверх обычной версии, без удаления данных.
2. Проверьте уведомления, раздел «Обновления», входы в приложение, сохранение APK в Download/SmartVoice и120% громкости через скринридер.
3. После проверки откройте черновик, нажмите Edit → **Publish release**. **Set as latest release** оставить включённым. Загружать файлы самому не нужно.

В этой версии авто-проверка работает при каждом новом входе, без интервала6часов. Готовые APK остаются в Download/SmartVoice после установки; пользователь может удалить их самостоятельно. В разделе «Обновления» есть ручная проверка, продолжение установки и открытие папки. Черновики и пререлизы пользователям не предлагаются. Совпадающая установленная версия повторно не предлагается.

Адрес опубликованного канала: `https://github.com/UMEDJON12/smartvoice-tj-updates/releases/latest/download/update.json`. До первой публикации404 нормален. В `apkUrl` используется постоянный tag выпуска, подготовленный до draft, а не временный untagged-адрес.

Full — отдельный пакет, его нельзя помещать в latest обычной ветки. Этим APK Full не обновляется.

Проверки: `checks/upload-check-result.json` и [Actions](https://github.com/UMEDJON12/smartvoice-tj-updates/actions/runs/40391104820). Проверены скачанные APK/JSON, SHA256, размеры, пакет, версия и исходный сертификат через apksigner/aapt. Это не проверка на физическом телефоне.

Для следующего агента: `tools/prepare_upload_request.py`, `tools/direct_upload_client.py`, `.github/workflows/direct-draft-upload.yml`. Новые APK загружаются прямо в Release через одноразовую зашифрованную сессию; после завершения токен отзывается. Постоянные персональные токены, Android-ключ подписи и пароль не публикуются. Всегда оставлять выпуск черновиком до решения владельца.
