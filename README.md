# Обновления SmartVoice.TJ🇹🇯

Опубликованная версия: [SmartVoice 5.2.30-TJ](https://github.com/UMEDJON12/smartvoice-tj-updates/releases/tag/v5.2.30-TJ).

Подготовлена **SmartVoice 5.2.31-TJ (code 4147), SmartVoice-TJ39.apk**.

**[Открыть черновик 5.2.31 для проверки и публикации](https://github.com/UMEDJON12/smartvoice-tj-updates/releases/tag/untagged-5a573650a9922acf053c)**

APK и update.json уже загружены и независимо проверены. Новый выпуск ещё не опубликован.

1. Скачайте APK39 и установите поверх своей SmartVoice 5.2.29/5.2.30, без удаления данных. Новый загрузчик начнёт работать после установки.
2. Проверьте запуск, речь, сохранённые назначения голосов, раздел «Обновления» и доступность через скринридер.
3. После проверки откройте черновик под UMEDJON12, нажмите **Edit → Publish release**. **Set as latest release** оставьте включённым. Загружать файлы самому не нужно.

Добавлены ограниченные повторы скачивания, сохранение неполного файла и безопасная докачка. Улучшены этапы прогресса и сообщения об ошибках. Перед предложением обновления проверяется доступность APK. В описании — только нововведения. Готовые APK остаются в Download/SmartVoice после установки.

Черновик не предлагается пользователям. Пока установлен APK39, а опубликован APK38, сообщение об отсутствии более новой версии правильно. Для проверки скачивания из APK39 потребуется следующий выпуск с большим versionCode.

Канал: `https://github.com/UMEDJON12/smartvoice-tj-updates/releases/latest/download/update.json`. Обычный пакет `tts.smartvoice.umedjon`; Full имеет отдельный пакет и не относится к этому каналу.

Проверки: [Actions](https://github.com/UMEDJON12/smartvoice-tj-updates/actions/runs/40447103503) и checks/upload-check-result.json. Проверены скачанные APK/JSON, SHA256, размеры, версия, пакет и исходный сертификат. Компьютерные проверки не заменяют проверку на физическом телефоне.

Для следующего агента: tools/prepare_upload_request.py, tools/direct_upload_client.py, .github/workflows/direct-draft-upload.yml. Используется одноразовая зашифрованная сессия загрузки. Постоянные токены, Android-ключ подписи и пароль не публикуются. Выпуск оставлять черновиком до решения владельца.
