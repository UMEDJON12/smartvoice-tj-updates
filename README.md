# Обновления SmartVoice.TJ🇹🇯

Опубликована [версия 5.2.41-TJ](https://github.com/UMEDJON12/smartvoice-tj-updates/releases/tag/v5.2.41-TJ).

Подготовлено исправление **5.2.42-TJ, code4158, SmartVoice-TJ50.apk**.

**[Открыть черновик: скачать APK и опубликовать после проверки](https://github.com/UMEDJON12/smartvoice-tj-updates/releases/tag/untagged-b6dc6c5bdd5ed36ff012)**

Войдите как UMEDJON12. В Assets скачайте SmartVoice-TJ50.apk и установите поверх обычного SmartVoice без удаления данных. Full имеет отдельный пакет. После проверки: Edit → Publish release, Set as latest release оставить включённым.

Исправлена потеря выбранной временной Google-модели при разных обозначениях одного пути Android. Повреждённый импортированный набор больше не скрывает здоровые Microsoft/Google/другие голоса и не прерывает обновление каталога. Добавлено восстановление из ZIP. Исправлены согласование таджикского TTS с распознаванием и конфликт слова «як» с украинским правилом.

После установки откройте управление голосами. Исправные модели должны снова отображаться. Неполный Google-набор, чьи файлы уже потеряны версией41, восстановите повторным импортом ИСХОДНОГО GoogleTTS-full-configuration.zip. Восстановить отсутствующие модельные данные без исходного ZIP невозможно. Отсутствующий английский файл в том ZIP не блокирует импорт русских вариантов. Не удаляются существующие папки и назначения.

[Независимая проверка GitHub](https://github.com/UMEDJON12/smartvoice-tj-updates/actions/runs/41318207815) успешна: APK/JSON скачаны, размер/SHA256/пакет/версия/прежняя подпись подтверждены.21 группа/394590 компьютерных проверок; ошибка воспроизведена на исходниках41. Новую установку/синтез проверить на телефоне до публикации.

Полный Android-проект предоставлен отдельно в SmartVoice-TJ-5.2.42-Source.zip; автоматические Source code архивы GitHub содержат только updater-репозиторий. Черновик не опубликован. Дополнительные тестовые push-уведомления не отправлялись.
