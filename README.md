# Обновления SmartVoice.TJ🇹🇯

Этот репозиторий обслуживает обычную версию `tts.smartvoice.umedjon`.

Подготовлен **черновик 5.2.29-TJ (code4145), SmartVoice-TJ37.apk**. APK и `update.json` уже загружены; общая публикация остаётся за владельцем.

1. Установите тестовый APK поверх обычной версии, проверьте работу.
2. Откройте [черновик выпуска](https://github.com/UMEDJON12/smartvoice-tj-updates/releases/tag/untagged-c9bc51676d7d7a9388f0), нажмите Edit при необходимости.
3. После проверки нажмите **Publish release**. Оставьте **Set as latest release** включённым. Самостоятельно загружать файлы не нужно.

Приложение5.2.29 содержит автоматическую и ручную проверку, скачивание и переход к системной установке. Старую версию без этой функции нужно один раз обновить вручную. Совпадающая установленная версия повторно не предлагается.

Адрес опубликованного описания: `https://github.com/UMEDJON12/smartvoice-tj-updates/releases/latest/download/update.json`. До первой публикации ответ404 нормален. Черновики не доступны пользователям канала. В `update.json` используется постоянный tag выпуска, который создаётся до загрузки, а не временный `untagged` адрес.

Full — отдельное приложение и в этот latest-канал не помещается. Сопровождающая Full5.2.31 подготовлена отдельно только для совместимости резервных копий.

Проверки находятся в `checks/upload-check-result.json` и [Actions](https://github.com/UMEDJON12/smartvoice-tj-updates/actions). Независимая проверка скачивает APK/JSON, проверяет SHA256, размер, пакет, код версии и исходный сертификат через apksigner/aapt. Это не тест на физическом телефоне.

Для следующего агента: `tools/prepare_upload_request.py`, `tools/direct_upload_client.py`, `.github/workflows/direct-draft-upload.yml`. Новые APK загружаются прямо в Release через одноразовую зашифрованную сессию. Постоянные персональные токены, приватный ключ подписи и пароль в репозиторий не помещаются. Всегда сохранять выпуск черновиком до решения владельца.
